# Arctic YouTube Downloader

Accessible (TalkBack / NVDA / Narrator) downloader for Android and Windows.
MP3, M4A, WAV, MP4 with Low / Standard / High quality.
Only download content you have permission to save.

## Easiest install: let GitHub build it for you (no programming tools needed)

1. Make a free account at github.com and create a new repository (any name).
2. Upload everything in this folder (keep the `.github` folder and `lib` folder).
3. Open the repository's **Actions** tab, choose **Build Arctic YouTube Downloader**, press **Run workflow**.
4. Wait about 10 to 15 minutes. Open the finished run and download:
   - **Arctic-YouTube-Downloader-Android-APK**: unzip, copy `app-release.apk` to your phone, open it, allow "install unknown apps".
   - **Arctic-YouTube-Downloader-Windows**: unzip, run `arctic_youtube_downloader.exe`.
5. On Android, allow "All files access" on the first download. Files go to `Download/Arctic Downloads`.

If a build fails, copy the error from the run log and send it to Claude.
